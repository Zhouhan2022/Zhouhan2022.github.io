# 画布演示

这个页面演示三件事：**文字记录**、**可点击的超链接**、**行文 ⇄ 画布 两种布局切换**。

## 超链接演示

- 外部链接：[MkDocs 官网](https://www.mkdocs.org/)（点一下在新页面打开）
- 站内链接：[关于我](../about/index.md)（跳到同站的另一页）
- 同页锚点：[直接跳到下面的画布](#_3)（小技巧：中文标题的锚点会自动编号成 _3）

## 画布小节

下面这一小节默认按"行文"排版；点 **🖼 画布** 会切成一张"纸"，上面可以自由摆放文字（默认无边框）和图片，文字/图片都能拖动、缩放。

- **📄 行文** = 线性阅读版（手机/打印/复制用），顺序 = 数据里的先后顺序
- **📍 按位置排序** = 把画布上的实际位置变成行文顺序（先上后下、同高先左后右）
- **✏️ 编辑模式** = 拖动、右下角拉大小、双击改字、× 删除、＋文字/＋图片
- **⬇ 导出JSON** = 改完导出，把数组贴回本页源码的 `<script>` 里

## 站内编辑

每页右上角（编辑本页铅笔旁边）多了一个 **✏️ 站内编辑** 按钮：打开后左边是这一页的 Markdown 原文，右边可以开关预览。预览开关默认关闭，打开后才实时渲染，避免浪费资源。改完复制或下载，再去 GitHub 提交。
