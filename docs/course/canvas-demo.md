# 画布演示

这个页面演示三件事：**文字记录**、**可点击的超链接**、**行文 ⇄ 画布 两种布局切换**。

## 超链接演示

- 外部链接：[MkDocs 官网](https://www.mkdocs.org/)（点一下在新页面打开）
- 站内链接：[关于我](../about/)（跳到同站的另一页）
- 同页锚点：[直接跳到下面的画布](#_3)（小技巧：中文标题的锚点会自动编号成 _3）

## 画布小节

下面这一小节默认按"行文"排版；点 **🖼 画布** 会切成自由摆放的便签（可拖动、可缩放），点 **📄 行文** 再切回来。编辑模式里可以拖动、右下角拉大小、双击改字、× 删除、＋ 添加便签，改完点"导出JSON"。
