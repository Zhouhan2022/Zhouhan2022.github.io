## 🛠 管理入口（站主使用）

- **改文段**：打开任意页面，点右上角的 ✏️ 图标 → 在 GitHub 网页编辑器里直接增删文字 → 提交，网站自动更新
- **新建页面**：[➕ 新建页面](https://github.com/Zhouhan2022/Zhouhan2022.github.io/new/main?filename=docs/%E6%96%B0%E9%A1%B5%E9%9D%A2.md&value=%23%20%E6%96%B0%E9%A1%B5%E9%9D%A2%0A%0A%E8%BF%99%E9%87%8C%E5%BC%80%E5%A7%8B%E5%86%99%E5%86%85%E5%AE%B9%0A)
- **删除页面**：[🗂 管理页面](https://github.com/Zhouhan2022/Zhouhan2022.github.io/tree/main/docs) → 点进要删的文件 → 右上角垃圾桶图标删除
- ⚠️ 新建/删除页面后，还要到 [mkdocs.yml](https://github.com/Zhouhan2022/Zhouhan2022.github.io/edit/main/mkdocs.yml) 的 `nav` 里加/删一行，侧边栏才会显示（否则页面存在但导航里看不到）
