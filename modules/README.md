# 模块约定（简版）

本仓库按「内容层 / 模块层」分离，改一块不碰另一块。

- `docs/` —— 内容层：Markdown 文章。加文章 = 加 `.md` + 在 `mkdocs.yml` 的 nav 登记。
- `docs/assets/modules/<name>/` —— 功能模块层：每个功能一个独立文件夹（`*.js` + `*.css`）。
  - 模块自带 README（用途、入口文件、数据格式）。
  - 删掉某个模块文件夹 = 删掉该功能，其他页面照常运行（git 可恢复）。
- 改动原则：改功能只动对应模块；改文章只动 `docs/` 里的 `.md`。
- 源码索引见仓库根目录 `SOURCE.md`。
